## Genuine Tensions Resolved (`Tension with`)

### 1. Zero-LLM Schema-Derived Write Integrity (`CapLite`) vs. Offline Code/Policy Compilation (`Baya`, `CaMeL`, `ToolFence`, `ActGov`, `FlowCheck`)
- **Entry A**: `"DON'T: Place SLM-generated security artifacts on the write-integrity path"` (`CapLite`, `arXiv:2611.17115` in `agent-sandbox-safety.md`)
- **Entries B–E**: `"DO: Compile web-agent tasks offline against a typed Trusted Website API and feed back only schema-level error diagnostics during replanning"` (`Baya`, `arXiv:2611.06039`), `"DO: Measure open privilege alongside attack success and utility"` (`ToolFence`, `arXiv:2609.37196`), `"DO: Confine the LLM to bounded record extraction and authorize against a verified, frozen policy"` (`ActGov`, `arXiv:2609.24446`), and `"DO: Compile LLM-authored UI behavioral constraints into deterministic static dataflow queries instead of prompting LLMs to review frontend code directly"` (`FlowCheck`, `arXiv:2608.28880`)
- **Resolution**: Added reciprocal `Tension with` notes across all five entries. Offline code compilation (`Baya`, `CaMeL`) and frontier/human-authored static policies (`ActGov`, `ToolFence`, `FlowCheck`) excel when frontier coders (`Claude Sonnet-4.6`, `GPT-5.6-Luna`) synthesize variable-count loops (`+12.2` to `+13.5` UA points on `Gemma-4`) or humans verify SMT rules offline. On `1.7B–35B` open-weight SLMs without human-authored domain policies, however, delegating runtime policy/program synthesis to the SLM either fails open (`Progent` `4.85%` ASR on `14/15` models; `IPIGuard` `3.12%` ASR on `13/15` models) or fails closed (`CaMeL` `>15%` unrunnable programs on `8/15` models, `68%` on `Granite-4.2-8B`, at `93.7k` tokens/ep), whereas zero-LLM schema derivation + pre-read write commitment (`CapLite`) achieves `0/13,935` (`0.00%`) ASR across `15/15` models at `17.1k` tokens/ep.

### 2. Bounded Causal Write Verification (`OverServe`) vs. Post-Call State Verification & Quiescent Sandbox Dry-Runs (`agent-sandbox-safety.md`, `skill-system-design.md`)
- **Entry A**: `"DON'T: Poll global backend quiescence to close a session or screen status endpoints only on idle backends"` (`OverServe`, `arXiv:2611.14808` in `agent-sandbox-safety.md`)
- **Entries B & C**: `"DON'T: Treat HTTP 200 / success tool return codes as workflow success without state verification"` (`agent-sandbox-safety.md`) and `"DO: Pair static skill checks with safety-constrained sandbox dry-runs and provenance-weighted evidence rather than alert-count thresholds"` (`skill-system-design.md`)
- **Resolution**: Added reciprocal `Tension with` notes across all three entries. Post-call state verification remains mandatory to catch silent partial execution, and sandbox dry-runs catch overt malicious skills (`F1 = 0.89`), *provided* post-write checks bind strictly to the causal `mutation_id` or first-seen `source_version` snapshot (`40 -> 22` median calls, `0` budget hits) within `<= 2–3` bounded reads and dry-run harnesses inject concurrent state-`churn` fault profiles rather than testing status tools only on quiescent mocks (`1.25x–1.50x` quiescent vs. `10.30x` geo-mean / `93.88x` peak amplification under `churn`).

### 3. VLM Resolution Parity (`SISS` / `ScaleGuard`) vs. Text-to-Image Rendering (`Pictionary`) & Structural Perturbation (`AlcaTRAz`) (`agent-sandbox-safety.md`)
- **Entry A**: `"DON'T: Downsample untrusted images into tiny thumbnails before VLM ingestion or rely on pixel-space smoothing"` (`SISS`, `arXiv:2611.16744`)
- **Entries B & C**: `"DO: Consider rendering untrusted prose as images as one prompt-injection layer, per model"` (`Pictionary`, `arXiv:2609.36121`) and `"DO: Stack input-level structural perturbation as an outer layer in defense-in-depth"` (`AlcaTRAz`, `arXiv:2609.03693`)
- **Resolution**: Added reciprocal `Tension with` notes across all three entries. `Pictionary` renders untrusted *text* into clean typographic images and `AlcaTRAz` perturbs *text* tokens (`73.4%`), whereas on *already-visual* untrusted assets downsampling `512x512` presentation views into `64x64` VLM thumbnails creates a `58.75%` cross-scale visual prompt-injection channel against which all five single-view pixel perturbations (`JPEG(75)`, Gaussian blur, `3x3` median, area resampling, `5`-rep random masking) have zero statistically significant effect (exact McNemar $p = 1.000$). Preserving `>= 224x224–336x336` VLM resolution parity cuts mean ASR to `6.85%` / `5.60%`.

### 4. Command-Level Parallel/Serial Accelerator Slot Splitting (`Metal Sandbox`) vs. Containment Boundaries (`agent-sandbox-safety.md`)
- **Entry A**: `"DO: Split parallel workspace commands from per-node serial accelerator slots and migrate only waiting commands exceeding handoff overhead via reserve-claim-commit"` (`Metal Sandbox`, `arXiv:2611.17294`)
- **Entry B**: `"DON'T: Use application-layer tripwires or PID signals as the containment boundary for a rogue agent"` (`Hard Stop`, `arXiv:2609.29808`)
- **Resolution**: Added reciprocal `Tension with` notes clarifying that prefix-based parallel/serial command classification and cooperative OS wrappers (`App Sandbox`, which provides no physical GPU memory isolation) govern **benchmark timing hygiene and queue scheduling** among cooperative rollouts (`-22.3%` batch time, `-40.4%` to `-51.1%` concentrated kernel loops above $T_{\text{mig}} \approx 1.86\text{--}2.16\text{ s}$), never hostile security containment.

### 5. 2-Hop Decentralized Capability Warmup (`GraphHarness`) vs. Centralized Topologies, Flat Teams & 1-Hop Schema Retrieval (`multi-agent-coordination.md`, `skill-system-design.md`)
- **Entry A**: `"DO: Pair 2-hop local capability warmup with contextual LLM routing memory in privacy- or scale-constrained decentralized graphs, and harden hubs against misrouting"` (`DecArena`, `arXiv:2611.15521`)
- **Entries B–E**: `"DON'T: Default to a fixed multi-agent topology"`, `"DO: Structure inter-agent communication around typed intents and bus substrates"` (`BusMA`), `"DO: Scale test-time compute on verifiable long-horizon tasks via parallel small flat teams rather than solo Best-of-N, one giant team, or manager orchestration"` (`multi-agent-coordination.md`), and `"DO: Induce tool dependency graphs via counterfactual sandbox execution and cap retrieval propagation at one hop with top-2 providers per input"` (`LIBRA`, `skill-system-design.md`)
- **Resolution**: Added reciprocal `Tension with` notes across all five entries. When agents share a trust domain (`N <= 50`) or hold full toolsets (`M = 10` flat teams), centralized/bus topologies avoid multi-hop hub fragility (`53.7% -> 3.2%` under $k=3$ misrouters), and `LIBRA` caps *centralized* full-schema prompt expansion at `1 hop` to avoid `2.7x` prompt bloat; when `100K+` owner-private `HMAC` tools are partitioned across `N = 10–1,000` peers (`Global Registry` = `Out of Context`), `2-hop` compact *domain-summary* warmup + contextual neighbor routing (`GraphHarness`, `53.7%` vs. `5.2%` `Reflex`) is required.

### 6. Human-Facing Devil's Advocate & Ceiling Effects (`arXiv:2611.14901`) vs. Automated Cross-Family Rosters, Challengers, Swap Debate & Dynamic Entropy Calibration
- **Entry A**: `"DON'T: Assign a standing devil's advocate persona in human-facing deliberation, or add a second deliberating AI near accuracy ceiling"` (`arXiv:2611.14901` in `agent-human-interaction.md`, plus evidence extension in `multi-agent-coordination.md`)
- **Entries B–E**: `"DO: Use heterogeneous, cross-family rosters for deliberation and joint verification"`, `"DO: Trigger mid-trace retrieval and specialist recruitment via an external non-answering Challenger with isolated channels"`, `"DO: Route requirement-to-code traceability by evidence locality and use symmetric Trace/Non-Trace swap debate instead of lexical retrieval or one-way critics"` (`multi-agent-coordination.md`), and `"DO: Dynamically calibrate consensus entropy and weight peer influence by evidence grounding in multi-agent debate"` (`recursive-improvement.md`)
- **Resolution**: Added reciprocal `Tension with` notes across all five entries. Non-answering channel-isolated Challengers, judge-adjudicated `Trace`/`Non-Trace` swap debates, and selective entropy-triggered evidence injection improve automated reasoning because dissent is resolved or triggered selectively, whereas exposing human decision-makers directly to an unarbitrated every-round Devil's Advocate leaves `0.287–0.650` final disagreement, induces `0.298–0.426` human underreliance on the accurate peer AI, and lowers human accuracy ($p \le 0.005$) and trust ($p \le 0.032$). Likewise, adding a second cross-family AI over a multi-round single AI helps humans only when single-AI accuracy leaves headroom (`ReaLMistake` `0.733` vs `0.639`, $p = 0.027$; no gain near `0.984` ceiling on `Fact-check`).

### 7. Pre-Proposal Residual Shortlisting & Multi-Granular $L^2$ Gating (`RSI-PDEbench`) vs. Feedback-Poisoning `LOEO` Gates & Post-Migration Self-Tests (`recursive-improvement.md`, `agent-evaluation-quality.md`)
- **Entry A**: `"DO: Couple residual shortlisting with per-class and per-case non-regression gates in noisy scientific solver evolution, without treating operator residuals as a monotonic accuracy proxy"` (`RSI-PDEbench`, `arXiv:2611.14949` in `recursive-improvement.md`)
- **Entries B & C**: `"DON'T: Promote bundled text-space skill edits on aggregate clean validation accuracy alone"` (`SkillOpt`, `arXiv:2611.09348` in `recursive-improvement.md`) and `"DON'T: Gate post-migration code repairs on typical inputs, repairer self-tests, or LLM-filtered legacy-binding assertions"` (`arXiv:2611.08269` in `agent-evaluation-quality.md`)
- **Resolution**: Added reciprocal `Tension with` notes across all three entries. Training-split self-experiments and PDE operator-residual shortlisting serve strictly as *pre-proposal exploration filters* before an isolated supervisor gates candidates on held-out fine-grid reference-$L^2$ non-regression (unlike post-migration repairer self-tests used as an admission gate, Holm $p = 0.132$), while joint `(solver, policy, memory)` promotion under benign `50%` Gaussian noise still requires `LOEO` marginal validation whenever reference feedback may be adversarially poisoned.
