## Genuine Tensions Resolved (`Tension with`)

### 1. Lexical-Overlap Relay Guardrails (`DonkeyRail`, `arXiv:2611.21520`) vs. Synthesis-Only RAG Overlap Caps (`SNAPRAG`), Benign Threshold Calibration (`GradSafe`), & Interceptor Guards (`Model Armor`)
- **Entry A**: `"DON'T: Gate inter-agent relays on lexical overlap (BLEU/ROUGE-L/METEOR) or compute detector operating points via ROC interpolation"` (`agent-sandbox-safety.md`)
- **Entries B, C & D**: `"DON'T: Rely on topical content-moderation classifiers to stop verbatim RAG corpus extraction"` (`SNAPRAG`, `arXiv:2611.12241`), `"DO: Calibrate safety-detector thresholds on realistic benign traffic, per target model"` (`arXiv:2609.36849`), and `"DO: Filter prompt injections and jailbreaks at the interceptor layer using Model Armor"` (`adk-security-and-evaluation.md`)
- **Resolution**: Added reciprocal `Tension with` notes across all four entries. Output-to-chunk `ROUGE-L` caps work on **synthesis-only proprietary RAG endpoints** where raw passage dumping is never authorized (`<= 1.0%` vs. `68.5%–96.9%` chunk extraction), whereas in **inter-agent email/message relays where verbatim quotation and template reuse are authorized**, surface `BLEU`/`ROUGE-L`/`METEOR` guardrails falsely flag `100%` of completed quotations and templates (`30/30` `gpt-6-luna`, `93/93` `gpt-6.1-sol`) while missing `8/19` (`18/19` calibrated) paraphrased/encoded functional relays (`0.5272` pooled functional/benign `AUC`), and threshold recalibration cannot overcome feature non-identifiability or omitted external policy (`Proposition 2`).

### 2. Pre-Action Coding Contracts (`arXiv:2611.19549`) vs. Post-Completion Diff CWE Analysis (`NameTrap`, `arXiv:2610.34253`)
- **Entry A**: `"DON'T: Defer irreversible coding-agent contracts to post-generation review or mix conflicting scratch allowances with command bans"` (`agent-sandbox-safety.md`)
- **Entry B**: `"DO: Enforce post-completion static and dynamic CWE analysis on coding-agent diffs rather than relying on pre-completion scans or prompt reminders"` (`agent-sandbox-safety.md`)
- **Resolution**: Added reciprocal `Tension with` notes. Post-completion diff scanning (`NameTrap` / `C3`) catches CWEs synthesized into final repository diffs and lets agents revert unauthorized file edits (`12 -> 1` in Study 1), **but cannot undo irreversible shell, network, or recursive-delete commands already executed mid-trajectory** (`5 -> 5` in Study 1, `2 -> 3` in Study 2)—requiring synchronous pre-action command/path gates (`C4`) alongside post-completion diff CWE analysis.

### 3. Pre-Invocation A2A Agent Card Screening (`SecCARD`, `arXiv:2611.18887`) vs. Cryptographic A2A Auth, Primary-Evidence Forwarding (`arXiv:2611.17520`), & Pre-Execution Skill Scanning
- **Entry A**: `"DO: Screen external A2A Agent Cards before orchestrator ingestion via schema gates, deterministic NLP rules, and an isolated read-only semantic judge"` (`adk-security-and-evaluation.md`)
- **Entries B, C & D**: `"DO: Enforce mutual agent authentication and Agent Card verification over A2A"` (`adk-security-and-evaluation.md`, backfilled with `**Scope:**`), `"DON'T: Delegate untrusted evidence reading to a weaker sub-agent without forwarding primary source records to the orchestrator or verifier"` (`multi-agent-coordination.md`), and `"DON'T: Use a pre-execution skill scanner as the sole admission gate for third-party skills"` (`skill-system-design.md`)
- **Resolution**: Added reciprocal `Tension with` notes across all four entries. JWS signatures and OIDC `audience` prove *publisher identity*, not free-text card safety (`28/310` untrusted wild cards across `36.1M` domains); unlike task-document reading (`arXiv:2611.17520`) where forwarding verbatim records to the orchestrator prevents weak-reader forgery laundering, forwarding raw `MALICIOUS`/`SUSPICIOUS` Agent Card prose to a tool-bearing orchestrator *causes* selection hijacking—so screen cards first in a frontier-tier (`GPT-5.5` `97.0%` recall at `1.7%` seed FPR; never uncalibrated `8B–14B` at `44.0%–46.5%` wild FPR) toolless, memoryless judge and pair admission with digest pinning and runtime invocation sandboxing.

### 4. Chain-Aware Fail-Closed Ancestor State (`Agent-ZTA`, `arXiv:2611.18999`) vs. Operational Substrate State Telemetry (`SST`, `arXiv:2611.05391`)
- **Entry A**: `"DO: Separate static multi-hop delegation bounds from live ancestor-state effective permissions and isolate downstream anomalies via branch-scoped containment"` (`multi-agent-coordination.md`)
- **Entry B**: `"DO: Project host-verified substrate state telemetry into operational tool selection rather than using static schemas or neutral placeholders"` (`skill-system-design.md`)
- **Resolution**: Added reciprocal `Tension with` notes. During *operational tool routing* (`SST`), omitting unavailable optional probes avoids `-19.2 pp` over-cautious abstention, whereas at the *security authorization (`PEP`/`PDP`) boundary* (`Agent-ZTA`), any missing or stale required ancestor security-state snapshot must be classified `unavailable` and fail closed to `Deny`.

### 5. MCP `Code Mode` Return-Shape Stubs (`arXiv:2611.19123`) & Prompt Pre-Analysis (`arXiv:2611.19439`) vs. Progressive JSON Disclosure, `LIBRA` 1-Hop Routers, Offline `Baya` Compilation, & `ShadowBench-MCP` Routing
- **Entries A & B**: `"DO: Annotate Code Mode tool stubs with explicit return-value shapes and bound router fallbacks rather than stacking front-door routers on strong coders"` and `"DO: Pre-inject deterministic analyzer outputs for open-weight models and resolve domain aliases server-side rather than exposing raw ISO-code MCP arguments"` (`skill-system-design.md`)
- **Entries C, D, E & F**: `"DO: Decouple semantic action commitment from interface-specific tool realization and repair realization locally"`, `"DO: Induce tool dependency graphs via counterfactual sandbox execution and cap retrieval propagation at one hop with top-2 providers per input"` (`skill-system-design.md`), `"DO: Compile web-agent tasks offline against a typed Trusted Website API and feed back only schema-level error diagnostics during replanning"`, and `"DO: Declare mandatory safety-tool chains in MCP routing policies and monitor pre-execution route drift against operational shortcut pressure"` (`agent-sandbox-safety.md`)
- **Resolution**: Added reciprocal `Tension with` notes across all six entries. `Code Mode` (`search()` + `execute()` with return-shape stub hints; `-22.7` and `-39.5` pp without hints) keeps intermediate results inside the script sandbox (`70–90%` fewer tokens) and renders front-door subset routers redundant (`-0.028` utility, `+1.45 s` slower on `Qwen3.8-27B`; `62%–100%` `"ALWAYS select"` hijacking) while trading `Baya`'s `0.0%` untrusted-web IPI guarantee (`327.15 s`) for `3.6–6.4 s` interactive latency on trusted catalogs; meanwhile, across `31` open-weight models (`0.6B–27.8B`), `14/31` (`45.2%`) emit zero MCP calls and `57.5%` of `315,910` calls pass invalid/wrong ISO codes (`52.4%` empty returns), making deterministic prompt `inject` (`10/10` models improved, `0` losses) the default unless checkpoint tool-calling and prose synthesis are verified.

### 6. MCP Provider-Identity Binding (`arXiv:2611.21577`) vs. `<server_id>__<tool_name>` Prefix Isolation & Descriptor Hash Pinning (`arXiv:2611.03555`, `ETUDE`, `A2M`)
- **Entry A**: `"DO: Bind MCP capability resolution to verified provider identities rather than tool names, unique prefixes, or model clarification"` (`agent-sandbox-safety.md`)
- **Entries B & C**: `"DO: Pin MCP tool descriptors and isolate offensive execution boundaries"` and `"DON'T: Trust MCP tool metadata without trace-aware vetting"` (`agent-sandbox-safety.md`)
- **Resolution**: Added reciprocal `Tension with` notes. Server-ID prefixes (`arXiv:2611.03555`), container digest leases (`ETUDE`), and registration hash pinning (`A2M`) block duplicate-name collisions, post-admission code drift, and overt prompt-injected descriptions, whereas `C06` (`arXiv:2611.21577`) shows that static, uniquely named tools with **zero imperative overrides** still divert `20.4%–69.6%` of benign requests (or stall `22.4%–52.8%` via clarification) when authority cues pair with compatible input schemas (`Δ_schema`), requiring host-enforced `(capability_class -> verified_provider_id)` bindings.

### 7. Online Detour Cueing (`ToolPulse`, `arXiv:2611.19275`) vs. File-Ledger Decoupling, MCP Fast-Fail Circuit Breakers, & Pre-Execution Step Verifiers (`SWE-VERIFIER` / `PAWM`)
- **Entry A**: `"DON'T: Trigger online detour cues on single errors or two-step repeats, replace concise reminders with auxiliary-LLM spotters, or equate detour cessation with bug-fix resolution"` (`skill-system-design.md`)
- **Entries B, C & D**: `"DO: Decouple agent context into file ledgers to prevent runaway reasoning loops"`, `"DO: Enforce fast-fail circuit breakers, output schema validation, and grounded-fulfillment gates for MCP tool faults"` (`skill-system-design.md`), and `"DO: Gate step-level action verification on low-confidence steps and keep the verifier transparent to the policy"` (`recursive-improvement.md`)
- **Resolution**: Added reciprocal `Tension with` notes. External permanent `MCP` faults (`91.3%`) require `<= 2`-retry fast-fail circuit breakers and pre-execution step verifiers (`<4%` steps) raise task pass rates (`+1.7` to `+24.3` pp), whereas inside mutable `SWE-agent` debugging single errors and `2`-step repeats reflect normal test reproduction or `100%` (`3/3`) autonomous self-recovery, `Qwen3.7-Flash` `Tactile Spotting` trailed bare `Reminder-Only` (`56.1%` vs. `67.8%`) while inflating `Strategic Fixation` triggers `4.74x`, and even `61.6%–90.9%` detour cessation left end-to-end bug-fix resolution flat (`101/270` baseline vs. `99–105/270`).

### 8. Optimistic Verifier Gap Sign (`arXiv:2611.21538`) vs. Cheap Post-Training Verifier Robustness (`arXiv:2609.33467`)
- **Entry A**: `"DO: Audit RLVR process verifiers on a model-free probe grid for selection error and gap sign, and couple pessimistic-biased rewards with saturation pilots"` (`recursive-improvement.md`)
- **Entry B**: `"DON'T: Pick an RL reward verifier by its agreement with a stronger judge alone"` (`recursive-improvement.md`)
- **Resolution**: Added reciprocal `Tension with` notes. Cheap rubric verifiers remain effective (`82%–95%` uplift in `arXiv:2609.33467`) when their errors are **pessimistic or rank-preserving** ($s \le 0.09$ or clipped small $\varepsilon$), whereas **optimistic** sufficiency/recall proxies ($\mathbb{E}[\tilde{V} - r^\star] > 0, s = 0.13\text{--}0.21$) drive padding hacks `2.3x–3.2x` harder per unit of $s \cdot u$ without increasing word count (`0.940` proxy vs. `0.731 -> 0.667` true faithfulness).

### 9. SLM Cross-Schema Schedule Overfitting (`arXiv:2611.21529`) & Alternating Curriculum-Execution Harnesses (`RoboACE`, `arXiv:2611.13034`) vs. Stronger-to-Weaker Skill Transfer, `SWE-Trail` Curation, & `WHALE`/`COEVO` Weight-Harness Alternation
- **Entries A & B**: `"DON'T: Equate in-domain SLM trace distillation or exact-reward RL gains with transferable search judgment without cross-schema minimality checks"` and `"DO: Alternate curriculum-harness and execution-harness revisions over frozen admitted task snapshots with isolated Consolidator profiles and reachable runtime manuals"` (`recursive-improvement.md`)
- **Entries C, D & E**: `"DO: Evolve skills with stronger models, deploy to weaker ones"` (`skill-system-design.md`), `"DO: Keep prior-attempt history in the trajectory collector and retain explicit multi-field plans in SFT targets when curating post-training trajectories"`, and `"DO: Alternate model weight updates and harness search"` (`recursive-improvement.md`)
- **Resolution**: Added reciprocal `Tension with` notes. Natural-language `SKILL.md` rules and multi-repo corrective plans transfer across tasks, whereas single-schema deletion traces (`|F| = 10`) teach `Qwen3-4B` a fixed `10`-check schedule (`92.2%` in-domain $\to$ `47.9%` OOD Exact vs. `100%` [`47/47`] on `Claude Haiku 4.5 + shrink`); and when foundation-model weights are frozen (`GPT-6.1`, $\pi_{0.5}$), co-optimization shifts from `(weights, execution harness)` to alternating `(curriculum harness, execution harness)` over locked snapshots $\mathcal{T}_k$.

### 10. Abstaining Guardrail `Best-of-N` (`GRACE`, `arXiv:2611.20983`) & Out-of-Model `Discriminative Revalidation` (`ProcReverser`, `arXiv:2611.20827`) vs. Verifiable Flat Peer Teams (`arXiv:2611.09798`) & `PACE` 6D Compute Parity (`arXiv:2611.17610`)

Where `arXiv:2611.09798` assumes an exact automated verifier on long-horizon search, `GRACE` targets **label-free dataframe QA** where `63.9%` of `4`-agent pools share zero agreeing pairs (`+3.8 pp`, $p = 0.03$ over majority voting at exact `Category B` `263`-pool parity under `PACE` Route II, while reporting its `39.0% -> 70.7%` `(N, r)` sweep as a `Category D` scaling curve); likewise, `ProcReverser`'s 5-role pipeline spends `3.9x–4.5x` single-agent tokens without `Category B/C` parity, whereas its deterministic Python `DR` gate (`+12.5 pp` / `+11.0 pp` `Pass@1`, `-44.1%` target executions, `13.11M -> 12.88M` tokens) delivers a zero-token Route II gain.
