## Core Concept

Categorizes data efficiency techniques into: data curation (quality filtering, deduplication), data augmentation (synthetic data, paraphrasing), curriculum learning (ordering data by difficulty), and data mixing (balancing domains). Provides decision criteria for when each technique improves model quality per training token.
