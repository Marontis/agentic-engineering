# Byzantine Node Placement in Decentralized Federated Learning

> **Paper**: [Optimizing Byzantine Node Placement in Decentralized Federated Learning](https://arxiv.org/abs/2609.01495)
> **Praxis source**: src:2609-01495v1

## Why Not a Skill?

Graph-theoretic adversarial optimization problem for distributed machine learning communication topologies.

---

## Core Concept

Studies adversarial vulnerability in decentralized federated learning (DFL). Rather than evaluating Byzantine attack strategies at fixed nodes, the paper investigates strategic node placement: selecting which communication graph vertices to compromise under a fixed budget to maximize malicious weight propagation.

## Relevance to Praxis

- Theoretical context for multi-agent network topologies and vulnerability assessment against compromised nodes.
